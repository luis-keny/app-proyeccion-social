# Historial de crédito

**Estado:** propuesta.

Para conciliar reportes y permitir cancelaciones individuales, se propone materializar sesiones con identificadores estables y guardar en la asistencia el crédito reconocido.

Recalcular desde la configuración actual podría alterar el pasado. Un saldo editable separado podría divergir del historial. El snapshot exige definir correcciones, anulaciones y efecto retroactivo antes de implementar.

Ver [modelo de datos](../database.md).
